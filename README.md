# AISCI210-Unit2-NN1

Materials for Unit 2 of UC Irvine AI SCI 210: **NN1**, a first introduction to neural networks using scikit-learn.

1. Click **Use this template** to create your own private repository.
2. In your repository, choose **Code → Codespaces → Create codespace on main**.
3. Wait for setup to finish. Open `NN1.ipynb` and select **.venv** as its Python kernel.

`NN1.ipynb` is a starter notebook with imports for scikit-learn's `MLPClassifier`, preprocessing, and model evaluation. Add the class notes and exercises there.

The Python 3.14 environment uses the same pinned `requirements.txt` as Homework 5 (updated October 22, 2026). It includes scikit-learn, NumPy, pandas, SciPy, Matplotlib, Seaborn, Vega-Altair, Plotly Express, JupyterLab, Notebook, and ipywidgets.

The environment is checked each time the Codespace starts. Packages are installed on the first start and when requirements change; ordinary restarts reuse the existing environment.

For local development with Python 3.14, run `bash .devcontainer/setup.sh`, then select `.venv` as the notebook kernel.
